# 預設 DOCX 版面基線

將此基線套用到沒有既有範本的繁體中文系統 UI 操作說明書。文件的章節順序與必要內容遵循目前 `ui-guide` plugin；使用者提供的既有文件可以提供視覺參照，除非明示，不能取代 plugin 的文件結構。既有範本或組織版型可提供樣式，但其專案名稱、畫面名稱與資料不進入共用基線。此基線為唯讀預設：使用者要求調整時，先**建立副本**並提升為可追溯的**版本**，記錄基線版本與**偏離項目**；建立副本並**不覆寫**原始基線。

## 執行環境與驗證結果

渲染器可用性、權限失敗、fallback 與未完成的視覺驗證，必須**對話中向使用者回報**。這些狀態**不得寫入 DOCX**；交付文件只保留使用者確認的操作內容，不新增執行環境警語、安裝提示或未驗證宣告。

## 首頁順序

1. **標題區塊**：置中深青綠標題；下一行為副標題；再下一行為「適用畫面」。標題必須描述功能，不使用專案或 release 的預設名稱。
2. **更新紀錄**：緊接標題區塊，以單一表格呈現「版本｜日期｜更新內容」，依版本由舊至新排列；不要在章節內另放更新紀錄。
3. **修訂狀態**：放在更新紀錄之後、版本依據之前。以一行或小型表格呈現「文件版本｜日期｜本次修訂摘要」。
4. **版本依據**：僅在具可驗證來源時呈現；可列 repository/tag、比較範圍、發佈時間與本次納入功能。沒有來源時整段省略，不保留空標題。
5. **使用提醒**：淡青綠底色提示框，說明畫面資料與截圖處理原則、紅框／編號意義、敏感資訊遮蔽要求。
6. **共通操作規則**：說明表單必填記號、查詢／重設、下載、確認提示與權限／資料狀態差異。

## 版型與容器幾何

本基線的文件結構與視覺樣式是兩個決策層：plugin 規範決定章節、步驟及驗證內容；基線或視覺參照決定標題層級、配色、框線、間距、圖片及表格外觀。

- 以頁面邊界、欄位、容器內距及適用頁首頁尾扣除後的**容器可用內容區**作為對齊基準。它不是整頁最大寬度。
- 表格預設相對於所在容器可用內容區置中。建置時明確設定表格對齊、段落／容器縮排與寬度關係，不依賴 Word 或文件函式庫的預設值；這可避免內建邏輯變動後表格漂移到左側。
- 表格總寬、欄寬及列高依內容與版型彈性調整，只要落在容器可用內容區；不採固定像素，也不要求每張表填滿可用區。等寬不是預設條件，同類表格應共用置中基準、表頭、框線與內距。
- 圖片、圖說與提示框依所在容器的對齊規則排版。較窄的元件保留大致相等的左右剩餘空間；只有明確指定時才靠左或靠右。

表格或圖片的寬度差異只要有內容或版型依據即可。結構檢查確認對齊屬性與尺寸落在容器內；最終 renderer 的逐頁檢視確認沒有靠左漂移、裁切、圖說分離或文字截斷。完整判準見 [visual-consistency-standard.md](visual-consistency-standard.md)。

## 內文與視覺系統

- 預設 Letter 直式；左右約 0.65 in、上約 0.67 in、下約 0.59 in。使用目標組織既有標準時，以其標準為準。
- CJK 正文字體必須使用本次 renderer 已驗證的明確字型名稱，並在 live text run 指定 East Asian 字型與 `zh-TW` 語言標記；不得以「Microsoft JhengHei 或等效字體」作為未驗證的跨平台實作。主標題／章標以深青綠；表格標頭採淡青綠；警示與點擊標註採紅色。
- 每章包含入口位置、操作流程、欄位與按鈕說明、修改成功後的影響、操作後檢核。圖說位於截圖下方。
- 每個操作小節的 Word 清單獨立重啟，顯示「步驟 1、步驟 2…」。紅框編號只用於同張圖內的控制項對照。
- 欄位／按鈕表最少使用「欄位或控制項、定義、必填、限制／選項」四欄；必要時加「顯示條件／結果」。
